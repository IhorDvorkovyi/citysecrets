Privacy Policy

Last updated: September 28, 2026

The CitySecrets application ("the App") is an internal tool used solely by the owner of the CitySecrets YouTube channel to upload and manage the channel's own videos through the YouTube Data API.

Data we access

When the channel owner signs in with Google, the App requests access to the YouTube account in order to upload videos, set video metadata (titles, descriptions, tags, thumbnails) and read basic channel and video information.

How data is used

Data obtained through Google APIs is used only to publish and manage content on the CitySecrets channel. It is not sold, shared with third parties, or used for advertising.

Storage

OAuth tokens are stored securely on the owner's private server and are used only by the App. No data of other YouTube users is collected or stored.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

Google API Services

The App uses YouTube API Services. By using it you also agree to the YouTube Terms of Service and the Google Privacy Policy. The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
